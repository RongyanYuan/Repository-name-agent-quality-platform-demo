## 复验入口

1. 打开「数据集与评测」，创建自定义数据集，填写名称与用途。
2. 点击「添加 Query」，选择产物类型并填写新任务；可选资产与固定版本。保存后应出现待运行记录，刷新应保留。
3. 点击「跑结果 & 评测」，确认运行范围和 Mock 情景。正常运行结束后应有逐条分数、交付物和 Case / Trace 入口。
4. 下载产物，核对其 Mock 标识；打开 Case / Trace 检查模块评分和 Evidence，再返回原数据集。
5. 再次运行时选择全部样本，检查新批次与旧批次均可选择；选择「仅评测已有结果」后 Trace 和产物 ID 应保持一致。
6. 增加两个任务并选择部分失败或全部失败，检查成功记录仍可打开、失败原因可见，旧批次保持原样。
7. 打开冻结准出/黄金预设，确认无法添加新成员但可运行；可运行数量仅含实际 Query / Trace，不含外部统计人口。

## 服务边界

当前下载交付物为明确标注 Mock 的 HTML 预览，并非真实 PPT / Word / Excel 文件。数据与运行批次保存在浏览器本地；清除浏览器站点数据后会丢失用户新增数据。真实生成及评测应通过服务适配接口替换本地 provider；现有数据集版本、输入快照、状态、失败原因和结果历史契约继续保留。业务门禁阈值与发布状态沿用原有配置，不由本次运行推导。
