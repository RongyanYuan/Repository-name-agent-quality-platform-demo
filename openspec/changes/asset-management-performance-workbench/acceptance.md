# 资产管理工作台验收

日期：2026-10-13。

| 项目 | 结果 |
| --- | --- |
| 统一资产目录与版本 | 通过：品味 Skill、生产 Skill、个人 Skill、Memory、Tool、System Prompt、其他能力均有多版本 Mock |
| 评分与贡献选择器 | 通过：产物评分归一到 0–2，按 Query 时间筛选，Trace 贡献去重，数据集/进化来源可反查 |
| 三窗口工作台 | 通过：范围筛选、版本表现/月度趋势、具体资产进化历史均可交互 |
| HTML 报告 | 通过：有效筛选后可下载，报告使用独立白底/深灰/蓝色主题，包含筛选快照、评分卡、月度趋势、Trace、归因、数据集链接和返回资产管理链接 |
| 历史版本报告曲线 | 通过：按版本记录时间连接历代版本平均分，时间 X 轴、0–2 分 Y 轴、每个点直接标注版本和分数；页面与报告复用同一个图表，Trace 与进化贡献表均显示版本 |
| 全版本范围 | 通过：资产版本可选择“全部版本（历史）”，历史与下载报告保留所有版本的对应数据与版本标识 |
| 进化数据范围 | 通过：按资产、固定源版本及归因精确匹配触发 Trace / 聚类归因集；显式成员优先，旧 Mock 集仅在没有成员记录时回退到来源 Case。治理窗口、准出、黄金、泛化、回归验证集和同 Trace 的其他模块集不作为本项进化输入展示 |
| 报告按钮与筛选门禁 | 通过：按钮名称统一为“下载报告”；选择资产类型或具体资产即可下载，全部时间窗口不再阻塞；无资产范围时保持禁用 |
| 页面精简 | 通过：移除上传个人资产、规划个人 Skill 操作入口，隐藏旧资产治理台账，仅保留资产表现和进化历史工作区 |
| 历史版本与人工数据保护 | 通过：修正自动生成的当前版本、状态与历史时间；评分绑定实际执行的 Skill 版本和最终产物评测，Trace ID 保持数字串；保留人工记录及冻结实验快照 |
| 单元测试 | 通过：最终全量回归 74 个文件 / 632 项；包含资产模型 18/18、资产工作台 3/3、身份迁移 9/9、本地数据层 20/20、页面回归 77/77 |
| Playwright | 通过：资产管理主链路 1/1，实际打开下载 HTML 验证曲线、具体分数、全版本表、精确来源集隔离，并从报告链接进入对应 Skill / 版本的数据集详情；下载保留原页面 |
| 静态检查 | 通过：TypeScript、build、OpenSpec strict、diff-check；4174 HTTP 200 |

所有新增资产数据为本地 Mock；没有接入真实评测 Agent、实验服务、发布服务或线上报告服务。报告内链接指向当前本地平台，可替换为真实报告服务返回的 URL。
