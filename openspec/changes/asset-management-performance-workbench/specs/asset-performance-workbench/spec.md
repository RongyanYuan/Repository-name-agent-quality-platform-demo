## Purpose

资产管理工作台让治理人员按资产类型、具体资产、固定版本和时间范围查看产物表现、Trace 贡献、进化历史及数据集来源，并导出可复查的 HTML 报告。

## ADDED Requirements

### Requirement: 资产范围筛选

系统 SHALL 提供资产类型、具体资产、资产版本、关键词、预设时间窗口和自定义开始/结束 datetime 筛选。筛选必须按资产类型 → 具体资产 → 版本级联，切换上级筛选时清除不兼容的下级值；未选择具体资产时版本筛选可以为空。

#### Scenario: 级联选择具体资产与版本

- **WHEN** 用户选择“品味库 Skill”并选择某个具体 Skill
- **THEN** 系统只展示该 Skill 的已登记版本，默认选中最新版本，且不会混入生产 Skill 或其他资产类型

#### Scenario: 自定义时间范围

- **WHEN** 用户填写开始和结束 datetime
- **THEN** 系统按样本覆盖时间与该区间的闭区间交集筛选，保存 URL 状态；结束早于开始时显示错误并返回空结果

#### Scenario: 全部历史版本

- **WHEN** 用户选择具体资产和“全部版本（历史）”
- **THEN** 系统展示全部已记录版本的表现及进化来源，历史与报告的每一条来源均带有资产版本；默认当前版本根据资产目录和真实记录状态确定，不按数组末尾推断

#### Scenario: 无具体资产的类型视图

- **WHEN** 用户只选择资产类型而没有选择具体资产
- **THEN** 系统展示该类型的聚合表现视图，第三窗口不显示具体资产进化历史

### Requirement: 资产版本表现与 Trace 贡献

系统 SHALL 对具体资产在所选时间范围内的每个版本展示产物平均分、有效评分样本数、每个归因进化项的去重 Trace 贡献数和关联数据集。平均分必须使用 0–2 产物最终评分；没有评分时显示“暂无评测结果”，不得填充默认分数。

#### Scenario: 版本表现对比

- **WHEN** 用户选择具体资产、版本范围和时间窗口
- **THEN** 系统按版本展示平均产物分、评分样本数、归因项和每个归因项的唯一 Trace 数

#### Scenario: 同一 Trace 命中多个进化项

- **WHEN** 一个 Trace 关联多个进化项
- **THEN** 该 Trace 可在各进化项贡献明细中出现，但资产总贡献数必须按唯一 Trace ID 去重

### Requirement: 资产类型聚合趋势

系统 SHALL 在仅选择资产类型时，使用该类型最新版本的已评分产物生成按月聚合的 0–2 平均分折线图，并展示该类型对最新版本产生贡献的唯一 Trace 总数。

#### Scenario: 月度趋势

- **WHEN** 用户选择“生产 Skill”并设置时间窗口
- **THEN** 系统按 Trace Query 时间月份展示最新版本的平均产物分；没有某月评分时不绘制虚假数据点

#### Scenario: 类别无评分

- **WHEN** 当前资产类型在时间范围内没有产物评分
- **THEN** 系统显示空状态和“暂无评测结果”，不显示无法验证的趋势结论

### Requirement: 具体资产进化历史

系统 SHALL 在选择具体资产后展示该资产的版本、PRD 归因、进化时间、贡献 Trace 数、进化状态和关联数据集，并允许跳转到数据集与评测工作台的精确对象范围。

#### Scenario: Skill 进化历史

- **WHEN** 用户选择某个品味或生产 Skill
- **THEN** 系统按固定 Skill 版本和 PRD 归因展示历史，仅显示触发进化的来源 Trace 及聚类归因数据集；每个数据集必须匹配该 Skill、固定版本和归因，不展示准出、泛化、回归、黄金或窗口验证集

#### Scenario: 非 Skill 资产历史

- **WHEN** 用户选择 Memory、Tool 或 System Prompt
- **THEN** 系统按对应治理对象和固定版本展示已明确记录的进化历史；没有明确记录时显示“未关联进化记录”，不得借用其他资产结果

### Requirement: HTML 报告下载

系统 SHALL 在选择资产类型或具体资产且没有无效时间范围时启用“下载报告”，支持全部时间和全部版本。具体资产报告的历史版本得分按版本时间连接为曲线，X 轴为版本生效或创建时间，Y 轴为 0–2，每个点显示版本与筛选窗口内的产物平均分；缺失评分不填零分。报告必须包含筛选快照、版本表现、Trace 贡献、归因、匹配固定版本的数据集链接和返回平台的有效链接，下载时保留原页面。

#### Scenario: 下载可复查报告

- **WHEN** 用户完成有效筛选并点击下载报告
- **THEN** 系统下载一个 HTML 文件，文件中的数据与当前筛选快照一致，并包含可点击的资产管理页面链接

#### Scenario: 没有选择资产范围

- **WHEN** 用户既未选择资产类型也未选择具体资产，或者结束时间早于开始时间
- **THEN** 下载按钮保持禁用；仅缺少具体资产、固定版本或自定义时间时不得阻止类型汇总报告下载

### Requirement: Mock 数据与边界状态

系统 SHALL 提供品味库 Skill、生产 Skill、Memory、Tool 和 System Prompt 的多版本、多月份 Mock 数据，并明确标识所有数据为 Mock；空评分、无进化项、无数据集和版本未记录必须分别展示清晰状态。

#### Scenario: 多版本资产覆盖

- **WHEN** 用户筛选品味库 Skill 或生产 Skill
- **THEN** 至少可以看到两个固定版本及其不同时间的产物评分和进化 Trace 贡献

#### Scenario: 无关联数据集

- **WHEN** 某个资产进化项没有关联数据集
- **THEN** 系统显示“未关联数据集”，不生成伪造的数据集链接
