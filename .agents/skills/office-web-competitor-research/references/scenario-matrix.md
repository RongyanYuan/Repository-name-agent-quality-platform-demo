# Scenario matrix

Office means a work task with a receiver, decision/action and delivery constraints. A marketing landing page can be Office; a personal finance dashboard can be non-Office. Do not equate Office with boring or non-Office with creative.

| ID | Context / job | Input | Output | Main question |
|---|---|---|---|---|
| A1 | Office: monthly operating review | Excel | interactive dashboard | correct figures + useful filters |
| A2 | Office: client proposal | PPT or Word | proposal microsite | preserve facts + adapt narrative |
| A3 | Office: onboarding knowledge | Word + diagram | searchable guide | completeness + navigation |
| A4 | Mixed: visual reference reproduction | image | webpage | layout fidelity vs invented behavior |
| B1 | Office: project status communication | one sentence | webpage | critical clarification + completeness |
| B2 | Non-Office: personal exhibition | one sentence | webpage | aesthetic preference + browsing |
| A5 | Office: campaign landing for client/approval receiver | brief + brand/data | webpage | facts, CTA and delivery constraints |
| B3 | Non-Office: public consumer/portfolio landing | one sentence | webpage | self-directed browsing and exploration |
| T1 | Same B1/B2 | template start | webpage | discoverability + adaptation cost |
| T2 | Same B1/B2 | inspiration start | webpage | preference expression + reproducibility |
| M1 | Same work brief | structured brief | web / PPT / image | recipient task and format tradeoffs |
| U1 | Same A1/A2 | updated source | existing output | refresh correctness + regression |

Pilot: B1 on accessible domestic products, then A1 on 3 products. Full round: A1/A2/A4/A5/B1/B2/B3/T1/T2/M1/U1 for shortlist. Classify context from receiver, decision/action, delivery constraints and source assets; never infer Office/non-Office from output type or visual style. Avoid testing every cartesian combination before learning.

Format-specific jobs: web supports nonlinear exploration and interaction; PPT supports paced narrative/presentation; image supports a single visual message/asset. These are hypotheses about affordances, not universal user preferences. Test exports, editability, access friction and receiver behavior.
