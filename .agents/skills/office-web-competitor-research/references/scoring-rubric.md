# Scoring rubric

## Outcomes, not one composite rank
Capture first draft and final result independently. Report: task completion, fact/data correctness, content completeness, visual hierarchy, functionality, mobile behavior, editability and delivery stage. Mark N/A where irrelevant.

Anchors (0–4): 0 unusable/incorrect; 1 major gaps; 2 partly useful with substantial repair; 3 meets task with minor repair; 4 meets task with coherent polish. Every subjective score needs a screenshot/artifact reference and short reason. Calibrate two raters on at least one result before broad ranking; disagreements remain visible.

## Objective metrics
- clarification_turns, clarification_questions, high_value_questions
- revision_turns, regression_count, manual_actions
- elapsed_seconds, active_user_seconds, waiting_seconds, clock_source (null if not measured)
- first_draft_acceptance and final_acceptance (true/false/null)
- communicated_requirements_met / communicated_requirements_total
- factual_errors, omitted_required_items, broken_interactions
- template_search_time, template_selection_actions, adaptation_turns
- cost/credits only when UI supplies evidence

Do not score undisclosed private preferences as requirements. Count answered questions separately from revisions. Minimal questioning is not automatically superior; compare final quality and total effort.

For auditable timing, record phase start/end for entry, clarification, generation, inspection, revision and export. High-value questions change acceptance, audience, data, permissions or delivery format; record the question text and why it qualifies.

## Web
Information architecture, real content, navigation/filter/button behavior, responsive layout, accessibility basics, readable text, consistency and deployment stage. Stage: text/code only → preview → usable interaction → saved/exportable artifact → shareable link → maintainable update. These are separate observed capabilities, not a guaranteed linear maturity ladder.

## PPT
Narrative, slide density, hierarchy, chart accuracy, editability, projection/reading and speaker use. No penalty for absent web interaction.

## Image
Brief adherence, legible intended text, composition, style, artifact defects and suitability as a visual asset. Do not require data filters or editable slides.

## Interpretation
A first draft after 8 answers is not equivalent to an immediate draft. Present a quality–effort frontier, not a multiplied “understanding score”. Blocked access never becomes a zero score. One trial cannot establish success rate. Marketing claims never fill missing measurements.
