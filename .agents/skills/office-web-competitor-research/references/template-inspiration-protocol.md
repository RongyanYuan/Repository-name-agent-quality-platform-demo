# Template and inspiration study

Distinguish: structural template, visual theme, starter prompt, reusable project/example, inspiration-only gallery. Record what reuse actually transfers: content, layout, assets, behavior, data or prompt.

Compare the same B1/B2 job from blank and gallery entry in fresh sessions. Counterbalance order for human participants. Record discovery/search, category labels, preview fidelity, template selection, attachment adaptation and post-generation revisions.

Questions: Can users search by job/role/industry/style? Is full output previewed? Are required inputs clear? Does one-click reuse work? Are data and facts replaced safely? Can users preserve brand, combine references or save team templates? Does the result resemble the preview? What licenses/attribution are disclosed?

Metrics: discovery success/time; selection actions; prompt length; clarification/revision turns; residual placeholder facts; first-draft and final quality. Unsupported gallery is a feature observation, not a failed generation test.

User mental-model hypotheses: gallery may help express taste, reduce blank-page anxiety, or anchor users to an unsuitable structure. Only interviews/behavior can distinguish these explanations. Do not infer intent from clicks alone.
